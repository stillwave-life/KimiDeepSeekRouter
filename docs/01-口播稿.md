## 成片口播（45–75 秒）

Claude Code 想接 Kimi 主脑加 DeepSeek 写码，常见两条路：自己改配置，或者双击一个启动器。

今天同机对照。一边：按文档手改 / 走官方直连。一边：Windows 上双击 `KimiDeepSeekRouter`，等绿灯，关掉旧的 `claude`，再开终端跑 `claude`，`/status` 看到本地 `127.0.0.1:8787`。

比三件事：速度、能不能一次跑通、账单大概什么感觉。数字上屏，口播不喊「省多少」。

手改侧：【秒数或步骤数】，【通/卡】。  
零配置侧：双击到绿灯【秒数】，`/status`【通/卡】。

同题编码题验收（可选镜）：同一份 prompt，pytest 红变绿——对照【秒】，路由【秒】。

文档 GitHub 免费，评论回「路由」。上不去 GitHub 的，私信「打包」，1.99 是同款教程加预打好的启动器。Kimi 订阅和双 Key 自己准备；可把配置丢给 AI，真 Key 只进本机 `.env`。
